## Borderline cases (detail)

### PMID 39903463 — CHART reporting tool development (Birkun et al. 2025, JAMA Netw Open)

This is a meta-paper about how chatbot-health-advice studies *report* LLM use — finding that 99.3% of 137 studies failed to describe prompt engineering, 99.3% used closed-source LLMs without versioning, and 60.6% omitted the date of LLM querying. These are exactly the M2/M6 deficiencies that PRISMA-trAIce was created to address, but for a different output type (chatbot health advice rather than systematic reviews). Could function as a comparator showing the same reporting-failure pattern in a parallel literature, or could be excluded as out-of-scope because it concerns LLM outputs *as clinical advice*, not LLM outputs *as scholarly writing*. Sean's call.

### PMID 38462064 — ChatGPT medical-response evaluation framework (Yan et al. 2024, J Biomed Inform)

The paper meta-analyzes 60 ChatGPT-in-medicine studies and finds the same reporting failures CHART/PRISMA-trAIce later named. It proposes its own "evaluation framework for LLM in medical inquiries." Borderline because the framework is domain-specific (medical Q&A) rather than scholarly-writing-general, but it's a 2024 instance of "reviewers proposing a reporting standard because the existing literature is methodologically weak" — which is itself a pattern relevant to the paper.

### PMID 39812777 — RAG-augmented LLM SR with development guidelines (Liu, McCoy, Wright 2025, JAMIA)

The bulk of this paper is a SR + meta-analysis of RAG-LLM performance in clinical applications (which is LLM-as-subject and would exclude). However, it explicitly proposes development guidelines and frames future work as (1) RAG + agent integration, (2) deep knowledge-LLM integration, (3) RAG within EHRs. The "RAG + agent" framing touches the agentic-writing-patterns scope's interest in RAG-as-grounding (a pattern Sean has built into scriptorium). If we include, we use it as evidence for the "grounding-against-corpus" pattern rather than for clinical RAG. If we exclude, we lose a citation for RAG-as-grounding that would otherwise have to come from outside this search.
